# 图标库与首批 50 个内置 App 图标

## 目标

用户反馈当前图标不全。目标是完整、易识别、离线可用的常用 App 图标，以及网页上的扩展图标下载能力。不能用通用图标占位、重复别名或只有目录没有实际文件的方式凑足 50 个。

## 内置范围

首批清单以 [BUILTIN_APPS_50.json](BUILTIN_APPS_50.json) 为准：包含 Chrome、Cursor、Firefox、Teams、Microsoft 365 / Office、Word、Excel、PowerPoint、Edge、Zoom、Photoshop 等，共 50 个唯一 App ID。

- 清单是需求计划，sourceUrl / hash 尚未填写，不代表资源已经下载。
- 每个条目都需要真实、完整、可识别的应用标志和可验证的来源记录。
- 新增别名不算新增一个 App；保留现有 App ID，避免破坏已保存配置。
- 检查现有 codex/chatgpt 的协议兼容逻辑。旧版别名兼容不应把真实不同产品的身份混淆。
- 常用 50 图标应随相关 App 产物实际打包，首次离线启动也能显示，不依赖先访问网站。
- 手机与电脑端显示同一 App 应使用一致目录/资源映射。目录应有一个可维护的数据来源，避免多处手写表逐渐不一致。
- 图标目录独立于快捷键白名单。增加一个可下载图标，不应自动授予启动新 App 或执行新命令的权限。

## 资源质量与来源

- 优先准确的原始 App / 官方品牌资源；已安装应用的系统原始图标可作为显示来源，但不能替代首批 50 图标的离线资源打包。
- 资源不得裁掉边缘、改变宽高比或只截取局部。显示采用 contain / 居中，并为各形状提供合适留白，透明背景优先。
- 建议移动端标准交付为透明 PNG 256×256，保留可靠的原始 SVG / PNG 来源用于后续更新；若使用 SVG，客户端与服务端必须明确支持该格式。
- 核实当前图标版本，记录原始 URL、许可/品牌使用条款链接、获取日期、内容 hash。不要伪造或猜测授权信息。
- Simple Icons 的项目许可不等于所有品牌标志许可；更新已有来源文档时保持准确。

## 网页功能

在现有 dashboard 增加显眼的“App 图标库”入口及独立页面，例如 `/icons`。

必须支持：

1. 按应用名称、canonical App ID、已知别名搜索。
2. 清晰显示完整图标、App 名称、可复制 App ID、内置/在线状态。
3. 预览与一键下载；下载文件名、MIME 和实际图片格式一致。
4. 通过 URL 中的 App ID 直接定位，例如 `/icons?app_id=chrome`。
5. 加载中、无搜索结果、未知 App ID、服务不可用、下载失败的可恢复状态。
6. 桌面和手机窄屏布局、键盘可操作性、正确的图片替代文字。
7. 展示实际来源/使用条款链接。产品流程不堆放内部实现或安全说明。

网站不能只是把内置 50 个原样列出而没有扩展能力。[清单](BUILTIN_APPS_50.json) 另外给出 10 个 web-only 示例用于演示；实现时可依可靠来源调整，但需至少证明内置清单以外的真实图标可下载，且无需重新发布 App 才能扩充服务器目录。

## API 与客户端衔接

建议沿用现有 Rust 服务扩展：

- `GET /v1/icons/catalog`：版本化目录，包含 id/name/aliases/version、图片格式/尺寸、下载地址、hash、来源、是否内置。
- `GET /v1/icons/{appId}`：已登记 App ID 的实际图标内容。
- 不存在的 ID 返回明确的 404；不要返回 200 + 错误页面伪装图片。
- 目录/资源支持合理 HTTP 缓存与版本更新。服务只查询已登记来源，不充当任意 URL 的下载代理。
- App 下载并缓存额外图标；断网、服务失败、损坏缓存时回退到内置或明确的备用图标，不阻塞启动/快捷键。
- 有限大小、超时、格式校验、可控缓存容量；避免无限下载或无限重试。
- 生产环境使用明确配置的中心服务 HTTPS 地址；不能硬编码虚构域名或开发机地址。
- Docker 构建上下文内应包含所需资源；不能依赖容器外的仓库相对路径。

## 验收标准

- 50 个唯一 App ID 都映射到实际资源，离线安装包检查能找到这些资源。
- 用户明确列出的 Chrome、Cursor、Firefox、Teams、Office、Word、Excel、PowerPoint、Edge、Zoom、Photoshop 全部存在且使用正确标志。
- 搜索、别名、按 ID 请求、下载文件内容、额外 web-only 图标与错误状态均有测试。
- 手机关闭网络后首次显示 50 个内置图标；额外图标下载后可离线读取缓存。
- 不记录哪些快捷键或按键被点击作为图标功能的“使用分析”。
- 至少覆盖完整图标库、搜索结果、空结果、错误、窄屏，以及 App 内置/下载/失败状态的截图测试，统一到当前版本 index。
